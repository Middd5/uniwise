# UniWise 🎓

**UniWise** — это веб-платформа для поступающих в вузы, помогающая управлять анкетой, планировать процесс поступления и взаимодействовать с представителями учебных заведений.

---

## 🚀 Функционал

* 👤 **Авторизация и регистрация**: создание аккаунта с хешированием паролей и JWT-токенами.
* 💾 **Сохранение данных**: личный кабинет пользователя с сохранением анкеты и плана.
* 🗄️ **База данных PostgreSQL**: надежное хранение профилей пользователей.

---

## 🛠️ Технологический стек

* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
* **Backend**: Node.js, Express.js
* **База данных**: PostgreSQL (`pg`)
* **Безопасность**: `bcrypt` / `bcryptjs`, `jsonwebtoken` (JWT), `dotenv`, `cors`

---
